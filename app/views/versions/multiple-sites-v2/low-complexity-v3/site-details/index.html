Before you start

In the next step, you'll need to tell us the following for every site:

  • site name
  • type of activity, for example construction
  • category of activity, for example maintenance construction
  • a drawing or plan of any construction work - you only need this for construction activities
  • activity description and methodology - a step-by-step explanation of how you will carry out the activity
  • maximum duration of the activity
  • schedule of when the activity will take place
  • possible impacts of the activity and ways to reduce them

Providing site locations

You can provide the site location in 2 ways:

  • upload a shapefile or KML file with the coordinates
  • enter the coordinates manually

Projects with multiple sites

You need to give separate location details for each site if your project has multiple sites.

If you're uploading a file you need to include all the sites in 1 file.

Defining the site boundary

The coordinates must mark the full boundary of every site, including space for any movement or small changes in the activity location.

Your file must only contain sites drawn as polygons (shapes), not points or lines.

Providing construction drawings or plans

If any of your activities involve construction of new marine works, you must upload a drawing or plan for each one, showing what you plan to build.

Your drawing does not need to be produced by an architect or other professional. A simple, clear drawing is fine, as long as it shows what you're building.

If you already have drawings from an architect, engineer or contractor, you can use those.

Your drawing must:

  • be a PDF (or other types - TBC)
  • (certain file size - TBC)
  • say whether or not it's drawn to scale

It also helps if your drawing shows:

  • key dimensions
  • the direction of north
  • the scale and original paper size, for example 1:200 at A3

If we approve your application, your drawing may be attached to your licence. This means it should be clear enough for anyone to understand.
