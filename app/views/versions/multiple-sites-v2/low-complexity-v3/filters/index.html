Three ways of filtering the projects list, all running against the same table and the same matching logic. Open each as an organisation user to see the Owner column and owner filtering.

Bespoke horizontal panel above the results. Keeps the full table width. Selected filters appear only once the panel is collapsed.

Top panel for the table width, MOJ tags for the selected filters, summary always visible, panel collapsed on load. Same Show radios as A and B, but picking "Projects by owner" without ticking anyone shows everything instead of raising an error.
